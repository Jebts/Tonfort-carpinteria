# Fotos del equipo

Reemplaza los 3 placeholders por fotos reales de cada persona.

- Proporción: **3:4** (vertical)
- Tamaño recomendado: **800 × 1000 px**
- Formato: `.jpg`
- Mantén los nombres: `santiago.jpg`, `natalia.jpg`, `esteban.jpg`

Los nombres se referencian desde `content/landing.ts` (`EQUIPO.personas[].foto`).
Si agregas o cambias una persona, actualiza ese archivo.
